# Zoothy UI Guidelines

## Philosophy

Zoothy is professional desktop-like business software.

Everything's naming in the ui should be like the user has not learnt accounts....so basic/easy/short naming which user can understand easily. Also not so basic because our users are founders/enterpreneurs, they have mind

The UI should feel:

- Calm
- Spacious
- Professional
- Fast
- Minimal

Never flashy.

---

## Whitespace

Whitespace is a feature.

Always leave breathing room between sections.

Avoid crowded interfaces.

---

## Forms

Labels above inputs.

Buttons aligned.

Avoid unnecessary borders.

One primary action per screen.

---

## Dashboard

Cards over tables.

Icons should be simple.

Quick actions visible.

---

## Tables

Comfortable row height.

Minimal borders.

Hover feedback.

---

## Colors

Never introduce new colors without updating theme.css.

---

## Components

Prefer reusing existing z-* components.

Avoid creating new CSS unless necessary.

---

## JavaScript

Business logic belongs in Service classes.

Page JS should only handle events.

---

## Printing

Print layouts are independent from screen layouts.

Absolute positioning is allowed only for printing.

---

## Responsiveness

Desktop first.

Tablet supported.

Mobile only where appropriate.

Printing pages are desktop-only.
