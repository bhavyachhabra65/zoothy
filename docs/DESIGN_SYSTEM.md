# Design System

Prefix

All reusable classes begin with

z-

Examples

z-container

z-row

z-button

z-input

z-label

z-checkbox

Spacing

Use CSS variables only.

Example

--z-space-1
--z-space-2

Typography

Title

Body

Small

Large

Buttons

Always use

z-button

Inputs

Always use

z-input

Never style native inputs directly.

Layout

Use flexbox.

Avoid absolute positioning except for printing.

Printing

Print CSS is completely isolated from application CSS.
